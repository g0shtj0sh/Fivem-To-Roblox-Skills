# Marques du jeu (rebadge automatique)

Le convertisseur ne laisse **aucune vraie marque** dans un véhicule : il lit la marque du mod
(`vehicleMakeName` de vehicles.meta, sinon le nom du dossier ou de l'archive), la remplace par la marque
du jeu ci-dessous, traduit le nom du modèle, remplace les emblèmes 3D par le logo et supprime les
lettrages. Ajouter une marque : une entrée dans `brands.json` + son logo PNG transparent dans `logos/`.
Logos peints dans les textures (cache-moyeu, pneu, écran) : `vehicles/<modèle>.json` (voir SKILL.md, « Marques »).

Noms non vérifiés dans les registres de marques : à contrôler avant publication du jeu.
